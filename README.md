# Assignment 4: Polyline and Polygon

This app demonstrates the use of polylines and polygons on a Google map component. The polygon depicts a rough outline of the eastern portion of Acadian National Park, while the polyline depicts the North Ridge Trail in Acadia National Park. The user is able to change color by adjusting the hue slider, as well as line thickness via the width slider. Tapping on the trail or the park polygon will yield some information about it via an alert.
